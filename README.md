### 🚀 Featured Projects

**🛍️ Retail Sales Analytics** — `Python` `PySpark` `Databricks` `AWS S3` `SQL` `Tableau`
Built a Bronze-Silver-Gold Medallion data pipeline on AWS S3, processing retail data with PySpark on Databricks Serverless. Developed 7 analytical KPI datasets powering interactive Tableau dashboards tracking $20.04M revenue, $286K profit, and 9,159 orders across 4 regions. Extended with Databricks Genie for AI-powered conversational analytics over the curated Gold Layer.

**🛡️ NIDS — Network Intrusion Detection System (ML & Agentic AI)** — `Python` `ML` `Streamlit` `Tableau` `Google Gemini`
Classifies network traffic as normal/attack, identifies attack type, and scores risk — trained on 28,000 records across 4 ML models. XGBoost achieved ~90% accuracy (F1 = 0.91); Random Forest handled the regression task at R² = 0.90. Includes a live 3-tab Streamlit app and an AI explanation layer that justifies each prediction using MITRE ATT&CK context.
